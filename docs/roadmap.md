# Feature roadmap

These features were recorded on 2026-09-30.
GitHub issues own the requirements, discussion and implementation status.

| Feature | Status |
| --- | --- |
| [Support multiple agent harnesses and desktop apps](https://github.com/VelvetAcorn/agent-auto-continue/issues/2) | Implemented: see [agent harness adapters](harnesses.md) and [desktop harnesses](desktop-harnesses.md) |
| [Auto-start when an agent becomes available, with turn limits and continuous mode](https://github.com/VelvetAcorn/agent-auto-continue/issues/3) | Implemented: see [continuations](continuations.md) |
| [Control the scheduler from a phone through an API or MCP layer](https://github.com/VelvetAcorn/agent-auto-continue/issues/4) | Implemented: see [remote control](remote-control.md) |
| [Keep the Mac awake until scheduled work completes across agents](https://github.com/VelvetAcorn/agent-auto-continue/issues/5) | Implemented: see [the keep-awake investigation](keep-awake-investigation.md) |
| [Iterate on UI quality of life with Claude models](https://github.com/VelvetAcorn/agent-auto-continue/issues/6) | In progress: see [the UI review](ui-review.md) |

Further integration candidates are Aider and Ollama.
The [harness issue](https://github.com/VelvetAcorn/agent-auto-continue/issues/2) contains the rationale, official documentation links and investigation boundaries.
